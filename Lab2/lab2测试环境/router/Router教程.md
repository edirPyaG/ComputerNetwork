# Router 程序使用说明文档

本文档基于《Router程序说明.pdf》整理，旨在指导实验中 Router 模拟程序的使用配置。

---

## 1. 实验拓扑模式

实验分为两种模式：正常直连模式和 Router 中转模式。

### 1.1 正常情况 (直连)

* [cite_start]**描述**：单向传输，Client 发送数据，Server 返回确认 [cite: 2]。
* [cite_start]**环境特征**：由于 Client 和 Server 均在一台主机上，基本不会发生丢包和超时 [cite: 2]。
* **配置示例** (仅供参考，请自行设计)：
  * [cite_start]**Client**: IP `192.168.10.1`, Port `12` [cite: 3, 4]
  * [cite_start]**Server**: IP `192.168.10.3`, Port `56` [cite: 5, 6]

### 1.2 Router 模拟模式 (中转)

* **描述**：Router 程序发挥转发功能。
  * [cite_start]**Client -> Server**: Router 对来自 Client 的数据包进行**丢包**或者**延时**处理后发给 Server [cite: 17]。
  * [cite_start]**Server -> Client**: Router 对 Server 发回的确认包**不做处理**，直接转发给 Client [cite: 17]。
* **配置逻辑**：
  * Client 的发送目标必须设置为 Router 的 IP 和端口。
  * Router 配置中需指定真实的 Server IP 和端口以便转发。

[cite_start]**拓扑示例配置** [cite: 18-25]：

| 节点             | 本地 IP (Local IP) | 监听端口 (Port) | 发送目标 (Target)                   |
| :--------------- | :----------------- | :-------------- | :---------------------------------- |
| **Client** | `192.168.10.1`   | `12`          | 发往 Router (`192.168.10.2:34`)   |
| **Router** | `192.168.10.2`   | `34`          | 转发给 Server (`192.168.10.3:56`) |
| **Server** | `192.168.10.3`   | `56`          | (接收来自 Router 的包)              |

## 2. Router 程序界面参数

[cite_start]根据程序界面，需配置以下参数 [cite: 30-43]：

1. **路由器配置**：
   * `路由器IP`：Router 程序绑定的本机 IP。
   * `端口`：Router 程序监听的端口（Client 发送数据的目的地）。
2. **模拟参数**：
   * `丢包率`：单位 `%` (double 类型)。
   * `延时`：单位 `ms` (int 类型)。
3. **服务器配置**：
   * `服务器IP`：真实接收端 Server 的 IP。
   * `服务器端口`：真实接收端 Server 的端口。

[cite_start]**日志说明** [cite: 48-51]：

* `Router Ready!`：程序已就绪。
* `Misscount: 20`：表示当前的丢包策略（每 20 个包丢 1 个）。
* `Delay: 3 ms`：表示当前数据包被延时处理。

## 3. 注意事项 (Critical Precautions)

在使用该程序时，请务必遵守以下规则，以免实验失败：

* [cite_start]**配置修改规则** [cite: 57]：
  * **第一次设置**：填写 IP、端口、丢包率、延时等所有信息后，点击 **“确定”** 按钮。
  * **后续修改**：IP 和端口信息在第一次填写确认后**不可修改**。如需调整丢包率或延时，请在填写新值后点击 **“修改”** 按钮。
* [cite_start]**最大包长限制** [cite: 58]：
  * 该程序转发包的最大大小为 **15000 字节**。
  * **警告**：请确保发送的数据包（Header + Data）不要超过该大小，否则会导致转发失败。
* [cite_start]**丢包率机制说明** [cite: 58]：
  * 丢包率参数虽然是 double 类型（百分比），但在内部逻辑中会转换为 `misscount`。
  * **机制**：日志中的 `misscount: n` 意味着**每经过 n 个包，丢弃 1 个包**（即固定间隔丢包，而非纯随机丢包）。
  * 每次发生丢包或延时，日志窗口均会打印相应信息。
