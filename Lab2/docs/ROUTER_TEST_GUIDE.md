# Router 模式测试配置指南

## 📋 网络拓扑

```
┌──────────┐         ┌──────────┐         ┌──────────┐
│  Sender  │────────>│  Router  │────────>│ Receiver │
│  Client  │         │          │         │  Server  │
└──────────┘         └──────────┘         └──────────┘
192.168.10.1:12    192.168.10.2:34    192.168.10.3:56
     │                    │                    │
     └──发送数据包──>     │                    │
                         └──转发(丢包/延时)──>│
     <───────────────ACK直接转发──────────────┘
```

## 🔧 详细配置步骤

### 步骤 1: 配置网络适配器（如果需要）

如果需要实际测试三个不同 IP，可以：
1. 使用虚拟机或多台电脑
2. 或在本机上配置多个 IP 地址（虚拟网卡）
3. **推荐**：在单机测试时使用 `127.0.0.1` (localhost)

**单机测试配置**（推荐初学者）：
```
Sender:   127.0.0.1:12000
Router:   127.0.0.1:12001  → 转发到 127.0.0.1:12002
Receiver: 127.0.0.1:12002
```

### 步骤 2: 启动 Router 程序

1. 运行 `Router.exe`
2. 在界面中配置：
   - **路由器 IP**: `192.168.10.2`（或 `127.0.0.1` 单机测试）
   - **端口**: `34`（或 `12001` 单机测试）
   - **服务器 IP**: `192.168.10.3`（或 `127.0.0.1` 单机测试）
   - **服务器端口**: `56`（或 `12002` 单机测试）
   - **丢包率**: `5.0`（建议从 5% 开始测试）
   - **延时**: `10`（单位 ms）
3. 点击 **"确定"** 按钮
4. 等待日志显示 `Router Ready!`

### 步骤 3: 启动 Receiver

**多机/虚拟机模式**：
```cmd
bin\x64\receiver.exe 64 192.168.10.3 56
```

**单机测试模式**：
```cmd
bin\x64\receiver.exe 64 127.0.0.1 12002
```

参数说明：
- `64` - 接收窗口大小
- `192.168.10.3` 或 `127.0.0.1` - 本地绑定 IP
- `56` 或 `12002` - 本地监听端口

### 步骤 4: 启动 Sender

**多机/虚拟机模式**：
```cmd
bin\x64\sender.exe 32 0.0 test_file.dat 192.168.10.1 12 192.168.10.2 34
```

**单机测试模式**：
```cmd
bin\x64\sender.exe 32 0.0 test_file.dat 127.0.0.1 12000 127.0.0.1 12001
```

参数说明：
1. `32` - 发送窗口大小（packets）
2. `0.0` - 发送端丢包率（设为 0，由 Router 控制丢包）
3. `test_file.dat` - 要传输的文件
4. `192.168.10.1` 或 `127.0.0.1` - Sender 本地 IP
5. `12` 或 `12000` - Sender 本地端口
6. `192.168.10.2` 或 `127.0.0.1` - Router IP（目标）
7. `34` 或 `12001` - Router 端口（目标）

## 📊 测试场景

### 场景 1: 基线测试（无丢包无延时）
**Router 配置**：
- 丢包率: `0%`
- 延时: `0 ms`

**预期结果**：
- 传输时间: 1-2 秒
- 吞吐量: 0.3-0.5 Mbps
- 重传次数: 0

### 场景 2: 丢包测试
**Router 配置**：
- 丢包率: `5%` → `10%` → `20%`
- 延时: `0 ms`

**预期结果**：
- 丢包率越高，传输时间越长
- 观察快速重传机制
- 观察拥塞控制窗口变化

### 场景 3: 延时测试
**Router 配置**：
- 丢包率: `0%`
- 延时: `10ms` → `50ms` → `100ms`

**预期结果**：
- RTT 增大，传输效率降低
- 超时重传阈值可能需要调整

### 场景 4: 综合测试
**Router 配置**：
- 丢包率: `10%`
- 延时: `50ms`

**预期结果**：
- 测试协议在真实网络环境下的性能
- 验证 TCP RENO 拥塞控制算法

## ⚠️ 重要注意事项

### Router 程序限制
1. **最大包长**: 15000 字节
   - 我们的包：Header(12) + Data(1024) = 1036 字节 ✅ 安全
   - SACK包：Header(12) + 8*SACKBlock(64) = 76 字节 ✅ 安全

2. **丢包机制**: 固定间隔丢包（非随机）
   - `misscount: 20` 表示每 20 个包丢 1 个
   - 丢包率 5% = 每 20 个包丢 1 个

3. **配置修改规则**:
   - 第一次配置后 IP 和端口不可修改
   - 修改丢包率/延时需点击 **"修改"** 按钮（不是"确定"）

### 发送端参数说明
```
sender.exe [窗口] [丢包率] [文件] [本地IP] [本地端口] [目标IP] [目标端口]
           ↓      ↓        ↓      ↓        ↓          ↓       ↓
           32     0.0      test   127...   12000      127...  12001
```

**重要**：发送端丢包率设为 `0.0`，由 Router 控制丢包！

### 接收端参数说明
```
receiver.exe [窗口] [本地IP] [本地端口]
             ↓      ↓        ↓
             64     127...   12002
```

## 🐛 故障排除

### 问题 1: Router 无法启动
**解决**：检查端口是否被占用，换一个端口

### 问题 2: Receiver 无法绑定
**错误**：`Bind failed`
**解决**：
1. 检查 IP 地址是否正确（单机用 `127.0.0.1` 或 `0.0.0.0`）
2. 检查端口是否被占用

### 问题 3: Sender 无法连接
**现象**：一直发送 SYN，无响应
**解决**：
1. 检查 Router 是否已启动并显示 `Router Ready!`
2. 检查 Sender 的目标 IP:Port 是否指向 Router
3. 检查 Router 的转发目标是否正确指向 Receiver

### 问题 4: 传输速度极慢
**原因**：Router 丢包率太高或延时太大
**解决**：
1. 降低 Router 丢包率（建议 5-10%）
2. 减少延时（建议 10-50ms）
3. 增大发送窗口
