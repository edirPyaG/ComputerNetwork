# Router 测试正确使用方法

## ❌ 错误的用法

```cmd
# 错误1: 参数顺序错误
bin\ARM64\sender.exe lab2测试环境\测试文件\2.jpg
# 结果: 窗口大小=0，传输卡死

# 错误2: 没有指向Router
bin\ARM64\sender.exe 32 0.0 test.jpg
# 结果: 直连到localhost:8888，绕过Router

# 错误3: 没有启动Router
bin\ARM64\sender.exe 32 0.0 test.jpg 127.0.0.1 12000 127.0.0.1 12001
# 结果: 连接失败
```

## ✅ 正确的用法

### 方法1: 使用脚本（最简单）

#### 传输普通文件
```cmd
scripts\test_router_localhost.bat
```

#### 传输图片文件
```cmd
scripts\test_image.bat
```

### 方法2: 手动操作（完整步骤）

#### 步骤1: 启动 Router
运行 `Router.exe`，配置：
```
路由器IP:      127.0.0.1
端口:          12001
服务器IP:      127.0.0.1
服务器端口:    12002
丢包率:        5.0
延时:          10
```
点击「确定」，等待 `Router Ready!`

#### 步骤2: 启动 Receiver
```cmd
bin\ARM64\receiver.exe 64 127.0.0.1 12002
```

参数说明：
- `64` - 接收窗口大小
- `127.0.0.1` - 绑定IP
- `12002` - 监听端口

#### 步骤3: 启动 Sender

**传输文本文件**:
```cmd
bin\ARM64\sender.exe 32 0.0 test_file.dat 127.0.0.1 12000 127.0.0.1 12001
```

**传输图片文件**:
```cmd
bin\ARM64\sender.exe 32 0.0 "lab2测试环境\测试文件\2.jpg" 127.0.0.1 12000 127.0.0.1 12001
```

参数说明：
1. `32` - 发送窗口大小（必须是数字！）
2. `0.0` - 丢包率（设为0，由Router控制）
3. `"文件路径"` - 要传输的文件（路径有空格需加引号）
4. `127.0.0.1` - Sender本地IP
5. `12000` - Sender本地端口
6. `127.0.0.1` - Router IP（目标地址）
7. `12001` - Router端口（目标端口）

## 🔍 问题诊断

### 问题1: 窗口大小为0
**症状**: 输出显示 `Send Window Size: 0 packets`
**原因**: 第一个参数不是数字，或者参数顺序错误
**解决**: 
```cmd
# 错误
sender.exe test.jpg

# 正确
sender.exe 32 0.0 test.jpg ...
```

### 问题2: 握手后卡住，没有传输
**症状**: 
```
[Sender] Handshake complete.
[Sender] File size: XXX bytes
(然后卡住)
```

**可能原因**:
1. 窗口大小为0 → 检查第一个参数
2. Router丢包率100% → 检查Router配置
3. 没有指向Router → 检查目标IP和端口

**检查清单**:
- [ ] 窗口大小 > 0
- [ ] Router已启动并显示 "Router Ready!"
- [ ] Sender的目标地址指向Router（不是Receiver）
- [ ] Router的转发地址指向Receiver

### 问题3: 传输非常慢
**症状**: 100KB文件传输超过30秒

**原因**: 之前的ACK丢包bug（已修复）

**解决**: 重新编译
```cmd
nmake rebuild
```

### 不同窗口大小对比
```cmd
# 小窗口
bin\ARM64\sender.exe 16 0.0 test.dat 127.0.0.1 12000 127.0.0.1 12001

# 中窗口
bin\ARM64\sender.exe 32 0.0 test.dat 127.0.0.1 12000 127.0.0.1 12001

# 大窗口
bin\ARM64\sender.exe 64 0.0 test.dat 127.0.0.1 12000 127.0.0.1 12001
```

---

**重点**: 第一个参数必须是窗口大小（数字），文件名是第三个参数！
