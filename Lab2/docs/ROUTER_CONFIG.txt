═══════════════════════════════════════════════════════════════════
  重要提示
═══════════════════════════════════════════════════════════════════

  ✓ Router 最大包长: 15000字节 (我们的包 < 1100字节, 安全)
  
  ✓ 发送端丢包率必须设为 0.0, 由 Router 控制丢包
  
  ✓ Router 配置后 IP和端口不可修改
     修改丢包率/延时需点击「修改」按钮(不是「确定」)
  
  ✓ Router 丢包机制: 固定间隔丢包
     丢包率5% = misscount:20 = 每20个包丢1个
  
  ✓ 必须先启动 Router, 再启动 Receiver, 最后启动 Sender
