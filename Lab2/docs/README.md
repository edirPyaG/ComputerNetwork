# RDT可靠传输协议实现

基于UDP的可靠数据传输协议，实现TCP核心功能。

## 快速开始

### 1. 编译程序

```bash
compile.bat
```

### 2. 运行测试

**方式一：手动运行**

终端1（启动接收端）：
```bash
receiver.exe 64
```

终端2（启动发送端）：
```bash
sender.exe 64 0.0 test_file.dat
```

**方式二：自动化测试**

```bash
test.bat
```

测试结果保存在 `test_results/` 目录。

## 功能特性

### ✅ 已实现功能

1. **连接管理**
   - 三次握手建立连接
   - 四次挥手关闭连接
   - 异常处理

2. **差错检测**
   - 16位Internet校验和
   - 自动丢弃损坏数据包

3. **确认重传**
   - 累积确认（Cumulative ACK）
   - 选择确认（SACK）
   - 超时重传
   - 快速重传（3个重复ACK）

4. **流量控制**
   - 接收窗口通告
   - 发送窗口调整
   - 可配置窗口大小

5. **拥塞控制（TCP RENO）**
   - 慢启动（Slow Start）
   - 拥塞避免（Congestion Avoidance）
   - 快速恢复（Fast Recovery）

6. **性能测试**
   - 传输时间统计
   - 平均吞吐率计算
   - 可配置丢包率模拟
   - 详细性能指标

## 命令行参数

### 接收端

```bash
receiver.exe [接收窗口大小]
```

- `接收窗口大小`: 接收缓冲区大小（单位：数据包），默认64

**示例**:
```bash
receiver.exe 32    # 设置接收窗口为32个数据包
```

### 发送端

```bash
sender.exe [发送窗口大小] [丢包率] [文件名] [-v]
```

- `发送窗口大小`: 发送窗口大小（单位：数据包），默认64
- `丢包率`: 模拟丢包概率（0-1），默认0.0
- `文件名`: 要传输的文件，默认test_file.dat
- `-v`: 详细日志模式（可选）

**示例**:
```bash
sender.exe 64 0.05 myfile.txt      # 窗口64，5%丢包率，传输myfile.txt
sender.exe 32 0.1 test.dat -v      # 窗口32，10%丢包率，详细日志
```

## 协议设计

### 数据包格式

```
+-------------------+
|   RDT Header      |  12 bytes
+-------------------+
|   Data Payload    |  0-1024 bytes
+-------------------+
```

### RDT Header (12 bytes)

| 字段 | 大小 | 说明 |
|-----|------|-----|
| seq | 4B | 序列号 |
| ack | 4B | 确认号 |
| len | 2B | 数据长度 |
| checksum | 2B | 校验和 |
| flags | 1B | 控制标志 (SYN/ACK/FIN/SACK) |
| window_size | 1B | 接收窗口（单位：包） |
| sack_count | 1B | SACK块数量 |
| reserved | 1B | 保留 |

### SACK扩展

ACK包可携带最多8个SACK块：

```cpp
struct SACKBlock {
    uint32_t start;  // 已接收数据起始序号
    uint32_t end;    // 已接收数据结束序号
};
```

## 技术细节

### 多线程架构（发送端）

- **主线程**: 读取文件，发送数据包
- **监听线程**: 接收ACK，更新拥塞窗口
- **定时器线程**: 检查超时，触发重传

### 单线程架构（接收端）

- 阻塞接收数据包
- 验证校验和
- 缓存乱序数据
- 发送SACK确认

### 拥塞控制状态机

```
慢启动 → 拥塞避免 ⇄ 快速恢复
   ↑                    ↓
   └──────超时──────────┘
```

## 注意事项

1. **端口占用**: 默认使用8888端口，确保端口未被占用
2. **运行顺序**: 先启动接收端，再启动发送端
3. **防火墙**: 确保防火墙允许UDP通信
4. **文件权限**: 确保有读写文件的权限
5. **测试文件**: 如果指定文件不存在，会自动创建1MB测试文件

## 常见问题

**Q: 编译失败怎么办？**
A: 确保安装了MinGW g++，并且版本支持C++11标准。

**Q: 连接建立失败？**
A: 检查是否先启动了接收端，以及防火墙设置。

**Q: 性能很差？**
A: 尝试增大窗口大小，降低丢包率，或减小超时时间。

**Q: 收到的文件不完整？**
A: 检查校验和错误，可能是网络问题或程序bug。
