## 新旧版本对比

### 1. 协议头部改进

**旧版 (rdt_structs.h)**:
```cpp
struct RDTHeader {
    uint32_t seq;
    uint32_t ack;
    uint16_t len;
    uint16_t checksum;
    uint8_t  flags;
    uint8_t  window_size;  // 仅流量控制
};
```

**新版 (rdt_protocol.h)**:
```cpp
struct RDTHeader {
    uint32_t seq;
    uint32_t ack;
    uint16_t len;
    uint16_t checksum;
    uint8_t  flags;
    uint8_t  window_size;
    uint8_t  sack_count;   // ✨ 新增：支持SACK
    uint8_t  reserved;     // ✨ 新增：预留扩展
};

struct SACKBlock {          // ✨ 新增：选择确认块
    uint32_t start;
    uint32_t end;
};
```

### 2. 确认机制升级

**旧版**: 仅累积确认
```cpp
// 只能确认连续收到的数据
send_ack(expected_seq);
```

**新版**: 累积确认 + 选择确认
```cpp
// 可以告知发送端哪些乱序数据已收到
void send_ack_with_sack(uint32_t cumulative_ack) {
    // 构建SACK块
    for (auto seq : received_seqs) {
        if (seq > cumulative_ack) {
            sack_blocks.push_back({seq, seq+MSS});
        }
    }
}
```

**优势**: 减少不必要的重传，提高效率

### 3. 性能统计功能

**旧版**: ❌ 无性能统计

**新版**: ✅ 完整统计
```cpp
struct Statistics {
    uint64_t total_bytes;           // 总字节数
    uint64_t total_packets;         // 总包数
    uint64_t retransmitted_packets; // 重传次数
    uint64_t duplicate_acks;        // 重复ACK
    uint64_t timeouts;              // 超时次数
    double transmission_time_ms;    // 传输时间
    
    void print() {
        // 计算并显示吞吐率
        double throughput_mbps = (total_bytes * 8.0) / 
                                (transmission_time_ms * 1000.0);
    }
};
```

### 4. 丢包率模拟

**旧版**: ❌ 无法测试丢包场景

**新版**: ✅ 可配置丢包率
```cpp
extern double LOSS_RATE;  // 全局配置

inline bool should_drop_packet() {
    static std::random_device rd;
    static std::mt19937 gen(rd());
    static std::uniform_real_distribution<> dis(0.0, 1.0);
    return dis(gen) < LOSS_RATE;
}
```

**用法**:
```bash
sender.exe 64 0.1  # 10%丢包率
```

### 6. 拥塞控制完善

**旧版**: 基本RENO实现
```cpp
if (cwnd < ssthresh) {
    cwnd += MSS;
} else {
    cwnd += MSS * MSS / cwnd;
}
```

**新版**: 完整RENO + 详细日志
```cpp
if (ack > base) {
    if (cwnd < ssthresh) {
        cwnd += MSS;
        if (verbose) cout << " (Slow Start)" << endl;
    } else {
        cwnd += max(1, MSS * MSS / cwnd);
        if (verbose) cout << " (Congestion Avoidance)" << endl;
    }
} else if (dupACKcount == 3) {
    // Fast Retransmit + Fast Recovery
    ssthresh = cwnd / 2;
    cwnd = ssthresh + 3 * MSS;
    cout << "Fast Retransmit! cwnd: " << old_cwnd << " -> " << cwnd;
}
```
